## Welcome to the Semantic MediaWiki repository!
Semantic MediaWiki (SMW) is a full-fledged framework that, with many spinoff extensions (most of which are in the repositories below), can turn a wiki into a powerful, flexible knowledge management system. All data created within Semantic MediaWiki can be easily exported or published via the Semantic Web, allowing other systems to use it seamlessly. Please visit the SMW Website at https://www.semantic-mediawiki.org

## Help with development and testing
We are an open-source project and are dependent on contributions from the community! We invite you to pick one of our repositories and help us out where you can. Developers can create pull requests or help us fix bugs. Non-developers can help by testing, commenting on issues, or improving documentation here or at https://www.semantic-mediawiki.org.
